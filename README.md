# IT Academy - Sprint 2: TypeScript Basics

## 📖 Descripción
Proyecto de ejercicios prácticos centrado en el aprendizaje y dominio de TypeScript. Incluye retos sobre tipado estático, interfaces, tipos unión, manipulación de objetos y **Utility Types** (`Pick`, `Omit`, `Parameters`, `ReturnType`, `Awaited`, entre otros), así como la verificación estática de tipos mediante el compilador de TypeScript.

## 🛠️ Tecnologías
- TypeScript
- Node.js
- Vitest
- TypeScript Compiler (`tsc`)

## 🚀 Instalación

1. Clona el repositorio:
```bash
git clone <https://github.com/ypmodev/Tarea-S2_02.git>
```

2. Accede al proyecto:
```bash
cd it-sprint2-basics-ts
```

3. Instala las dependencias:
```bash
npm install
```

## ▶️ Ejecución
Ejecutar los tests:
```bash
npm test
```

Comprobar los tipos con TypeScript:
```bash
npx tsc --noEmit
```

## 📂 Estructura del proyecto
- `src/` → Ejercicios y tests de TypeScript.
- `package.json` → Dependencias y scripts.
- `tsconfig.json` → Configuración de TypeScript.

## 📸 Demo
Este proyecto no dispone de una interfaz gráfica. Los ejercicios se validan mediante tests automatizados con Vitest y la comprobación de tipos con TypeScript.
